# Challenges

Practice tasks tied to the chapters and real-world flows.  
Implement them in your own Vite + React + TypeScript (or Next.js) project with `"strict": true`.

| Challenge | Main topics | Level |
|---|---|---|
| Convert `groupBy` or `debounce` from JS to fully-typed TS | 02, 06, 09 | Beginner |
| Replace every `any` in a small file with `unknown` + narrowing | 03, 07 | Beginner |
| Model `User`, `Post`, `Comment` with realistic optional fields and relationships | 05 | Beginner |
| Build a `Status` union and a `statusLabel` function | 04, 06 | Beginner |
| Create `NewUser`, `UserPreview`, and `UserUpdate` from one `User` type | 08 | Intermediate |
| Discriminated union for an API response + a component that renders each case | 07, 10 | Intermediate |
| Typed `groupBy<T, K>` returning `Record<K, T[]>` | 09 | Intermediate |
| Convert the `useFetch` hook to `useFetch<T>` with no `any` | 09, 10 | Intermediate |
| Convert a React form (inputs + submit) to typed events and state | 10 | Intermediate |
| Typed dynamic page with `params` / `searchParams` | 11 | Intermediate |
| Typed Route Handler (`GET` + `POST`) with request body type | 11 | Intermediate |
| Explain five broken snippets out loud, then fix them | 12 | Intermediate |

After building, practice explaining each type choice out loud as you would in an interview.
